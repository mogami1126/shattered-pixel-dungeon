# MMO 第一版界面修订（4.0.2-MMO.1.1）

本次修订回应挑战描述无法打开，以及大背包应为连续大网格的反馈。

- 挑战列表的滚动区域转发点击：右侧 i 打开对应说明；可编辑时点击挑战行切换勾选；查看已有存档时保持只读。
- 大背包改成七列网格，至少显示 70 个非装备物品格，所有物品在同一张连续列表，超过屏幕可上下滚动，没有分页按钮。
- 容量仍由 LARGE_BAGS 修改器取消；未启用该修改器时保留原有背包布局。
- 中文、英文大背包说明与实际布局同步。

## 验证

- :core:mmoRegression：78 项回归检查通过。
- :android:assembleDebug：构建成功。
- emulator-5554 上覆盖安装，读取用户正在使用的第 4 个存档，无需新建存档。
- 实际打开大网格背包，点击装备能打开对应物品操作窗口。
- 实际打开存档的挑战列表，滚动到大背包行后点击 i，正确显示中文说明。
- 本次未注入物品、手工修改存档或推进游戏回合；安装前已备份应用 files。游戏正常保存会更新最后游玩时间等元数据；验证后角色位置仍为 215，生命仍为 13/20，挑战掩码仍为 523776，怪物仍为 132 个。
