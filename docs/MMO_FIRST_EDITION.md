# 破碎像素地牢 MMO 第一版（4.0.2-MMO.1.3）

这是基于当前本地破碎 4.0.2 制作的可玩版本。以破碎自身的职业、装备、怪物和 Boss 阶段为基础，加入密集刷怪、掉落与持续强化。后续根据实际游玩反馈调整。旧数值策划文件属于设计草案，以本文和本版代码为准。

## 开始游戏

新游戏 → 选择职业 → 设置中的挑战 →「第一版 MMO 预设」→ 返回并开始。

预设启用无处不在和下面九项修改；原版九项挑战仍可单独勾选。建议创建新存档体验，已有楼层不会重新铺怪、重新投放初始掉落。

| 修改项 | 本版实际效果 |
|---|---|
| 无处不在 | 普通楼层初始怪物生成倍率 100 倍，最多放满符合生成规则的空闲地块；保留入口和特殊地块限制，不把召唤陷阱乘以 100 |
| Loot Paradise | 普通随机地面物品数量乘 5，每普通层额外 2 份食物；钥匙和任务物品仍走原规则 |
| BIOCHIP | 战斗伤害、防御取区间中值；命中按期望概率累计，减少连续随机落空；检查怪物可看到实际血量和成长倍率。地图、掉落、特殊效果触发仍有随机性 |
| 大量掉落 | 按英烈 GRINDING_2/3 的抽取次数和楼层池：基础 1～3 次，MMO 追加 round(max(sqrt(1.5^(d−1)),d)) 次；可能抽空，普通物品与消耗品为主；不按经验过滤，无 Boss 固定 30 件奖励 |
| 无限成长 | 角色可超过 30 级；武器、防具、法杖、戒指强化无固定等级上限；灵能短弓也可接受强化 |
| 装备吞噬 | 同名普通武器、防具、戒指、法杖合并为 A+B+1（显示强化等级）。取消等级、鉴定、诅咒、附魔限制，状态取合并前高等级的一件，同级保留目标。独特装备与投掷武器不自动合并；已有重复装备在加载时整理 |
| 大背包 | 无限容量、七列连续网格，至少 70 个物品格，超出屏幕滚动；自动配齐四种原版分类袋及武器袋、戒指袋，加主背包共七标签 |
| 自动拾取 | 移动后收集周围 3×3 范围内可见、可达的普通散落物品；隐藏物、商店货物和箱子不自动开启；钥匙、露珠、特殊任务奖励等保留手动拾取流程；不隔两面墙取物 |
| 批量升级 | 使用升级卷轴选定装备后可选 1、10、100 或全部；消耗实际拥有的卷轴，一批只播放一次读卷动画 |
| MMO | 固定楼层成长：怪物生命、伤害、经验乘 1.5^(d−1)，命中与闪避乘 d。基础护甲不额外放大。完全不参考玩家属性，也适用于旧存档和召唤怪 |

额外掉落的分支按英烈 Challenges.extraLoot：1～2 层抽 0～9，3～6 层抽 1～8，7～10 层抽 2～7，其后抽 3～7；0～2 使用当前破碎普通随机生成器，3～7 使用当前破碎财富戒指消耗品生成器（等级 0、5、10、15、20），8～9 为空。此版移植分支规则与数量，具体道具由当前破碎生成器提供，未移植英烈修改全局道具生成牌堆的实现。原版掉落另行保留。

## 第一版成长公式

强化等级以大整数记录。原公式内部等级最高保留 +20 作为计算坐标，界面、存档和实际伤害使用完整等级。

武器、防具和伤害法杖在 +20 以内保留原版升级公式。之后延续各自原版线性斜率，再乘 `1.035^(完整等级-20)`。法师魔杖的内置法杖同步完整等级；嬗变后的同类装备保留额外等级。

角色超过 30 级之后，下一级经验为 `5 × (当前完整等级+1)`，基础血量继续按每级 5 延伸。天赋和职业解锁仍按原版阶段，不无限增加天赋点。

根骨戒指额外生命倍率为 `1.035^额外强化等级`；精准和闪避分别继续使用 `1.3` 与 `1.125` 的指数增长。韧性戒指继续按缺失血量比例提供减伤。戒指诅咒和魔法免疫保留其限制。

攻速增长最多落实为每标准时间 256 次动作，超出的攻击频率折入伤害倍率。移动速度也最高 256 倍；秘法效果、充能和财富有实际效用上限，避免无限触发和掉落循环。戒指显示等级仍可持续增加。力量需求、充能上限、范围等工具属性使用有界坐标。神器和饰物保留原版成长上限。

## MMO 固定楼层成长

`d` 为当前楼层，怪物生命、伤害与经验乘 `1.5^(d−1)`，命中和闪避乘 `d`，沿用英烈 MMO.java 的成长系数。防御减伤沿用怪物原版基础值，不加玩家防具补偿；怪物种类差异与 Boss 阶段保留。旧存档中已经保存的玩家实力快照不再使用。

此版不做成长速度平衡。装备合并换算为实际等级守恒：显示 +0 对应实际 1 级，因此 A、B 两件合并后显示 A+B+1。例如 0+0→1、1+1→3、1+18→20。高等级装备的附魔、刻印、诅咒及其已经去除的状态优先；不通过反复调用 upgrade 来实现合并，避免随机抹去附魔或重新引入诅咒。

## 数值与回合保护

实际数值使用 `GameNumber`：约 15 位有效数字的尾数和大整数十进制指数；强化等级、扩展经验也使用大整数。没有直接把所有 int 改成 long。

生命内部保留原版坐标，实际伤害转换为该目标的生命坐标后交给原有阶段逻辑。小于一个内部生命单位的伤害累计余数，巨量攻击饱和到足以致死的安全包，避免溢出变成负数或 1 点伤害。怪物不额外增加玩家防具快照补偿伤害。治疗药水继续以生命比例恢复，不把巨量实际生命转回 int。

调度时间改为 double；角色正时间消耗至少 1/256。回合超过 10 秒且仍在等待角色动画时，尝试完成挂起的移动、跳跃或攻击回调并同步贴图位置。该保护只修复等待中的动画回调，不能修复所有无限逻辑循环，也不保证任何卡顿都能恢复。

大背包仍受设备内存限制，金币、能量和物品堆叠数量保留有界整数。炼金、商店和 NPC 沿用原版主要规则；铁匠的高等级强化限制在无限成长模式下放宽，价格规则保留。本版不增加测试无敌、赠送卷轴或跳 Boss 菜单。

## 验证边界

回归入口：`:core:mmoRegression`；APK 构建入口：`:android:assembleDebug`。测试代码位于 core 的 test 源集，不进入游戏运行菜单。

覆盖巨量数值计算和存取、百万级强化、分数伤害、根骨生命、扩展经验、确定性命中、固定楼层成长、合并、背包、极短动作时间、普通/首领奖励、法师魔杖同步、移除玩家护甲补偿、国王第三阶段延迟伤害死亡和天狗第一阶段转换。Boss 检查是代码级回归，不能等同于模拟器中完整通关。

模拟器验证记录和构建日志保存在工作区 `.research`，最新修订记录见 `MMO_V1_3_VERIFICATION.md`。
