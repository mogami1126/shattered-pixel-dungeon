# MMO 1.6：自动拾取漏物品

原实现通过反射检查 doPickUp 的声明类，仅允许普通物品、装备和投掷物。炸弹、钥匙、露珠、部分任务物品、文档、神器成长材料等重写了拾取方法，因此被整体排除。

移除声明类筛选。范围内每件物品调用自身 doPickUp(hero, heap.pos)，保留炸弹引线熄灭、钥匙日志、露珠治疗或水袋收集、任务效果和成长材料的正常流程。金币和能量晶体保留既有饱和累加逻辑。自动拾取作用域内抑制 spendAndNext/spendAndNextConstant，避免每件物品消耗回合或提前结束正在处理的移动；使用 finally 恢复状态，不影响之后的正常行动。

范围仍为移动后周围可见且可到达的 3×3 地面物品。不打开箱子、不购买商品。自身拾取规则返回 false 的物品仍留在地面，例如无需治疗且水袋装满的露珠、已经触发且不可收回的喧闹炸弹，不会因自动拾取被删除。

验证：120 项回归检查通过。新增实际物品堆测试验证炸弹入包且熄火、钥匙进入 Notes 而非背包、露珠治疗、拒绝拾取物品留在地面、箱子不被打开、整批拾取不增加回合耗时、异常后作用域恢复。Android Debug 构建成功，已覆盖安装至 emulator-5554，启动没有 AndroidRuntime 致命异常。模拟器中未主动推进回合，未进行实际场景炸弹拾取演示；机制验证为代码级回归。
