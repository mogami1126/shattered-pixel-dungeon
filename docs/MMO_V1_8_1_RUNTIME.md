# MMO.1.8.1 模拟器实测

安装到本机 pixel_7_-_api_36_0，ADB emulator-5554。测试使用新建的隔离槽6，标记 MMO18-ISOLATED-TEST。原玩家存档槽1没有进入或推进。

## 实际战斗

在复制的下水道地图中设置第6层倍率，仅开启 MMO、BIOCHIP、无限成长，关闭无处不在。这是隔离战斗测试场景，不代表正常爬到第6层或完整通关测试。

- 小鼠原生8HP，预期 8×1.5^5=60.75；实际面板显示60.8HP、生命和伤害倍率约7.6。
- 目标满血，使用+20单手剑攻击一次，小鼠死亡，经验0→7，击杀数0→1，地图敌人数1→0。
- 武器基础伤害中点61，另有正常力量加成，攻击仍落在目标血量1～2倍之间。英烈原防秒杀分支会在此区间削减伤害；当前实测直接击杀，没有残留1HP。
- AndroidRuntime与libgdx日志未记录崩溃。

## 回收界面与实际数量

发现1.8竖屏回收窗口过宽，ScrollPane内容摄像机在窗口resize前定位，材料格落到窗口之外。修正为按屏幕宽度决定列数，并在resize后定位滚动内容。打包并安装1.8.1，版本码928。

实际点击+2匕首并选择加一个，预览+3级，符合3×0.9=2.7四舍五入。实际选择10瓶药水的一半，再切换滑选模式拖过+2防具。合计选7件材料：2.7+2.43+5=10.13，预览增加10级。确认后存档验证：单手剑真实+30，匕首和防具已消耗，药水剩5瓶，没有mmo_forge_units余量字段。未喝药，未推进玩家原存档。
