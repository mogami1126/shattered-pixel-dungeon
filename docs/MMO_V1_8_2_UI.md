# MMO 1.8.2 手机界面适配

大背包原先固定七列，且绕过原版针对较大格子的缩减逻辑。现在按屏幕安全区域、窗口缩放和边框计算整列数量；竖屏测试为六列，横屏为七列。列表保持连续滚动，底部包裹标签的高度单独预留。大背包在安全区域居中。

回收强化窗口使用相同的安全区域尺寸预算，底部两个按钮等分宽度。窗口不再继承物品弹窗的偏移，独立居中；窗口定位完成后重新放置滚动内容摄像机，避免显示和触摸坐标偏离。

验证：Android debug 构建成功。API 36 模拟器 1080×2400 竖屏、2400×1080 横屏，挑战掩码 523776（包括大背包）。实际检查背包与回收窗口边界、包裹标签、滚动，以及滚动后点击材料打开对应数量菜单。运行时过滤日志未见 AndroidRuntime 致命异常。未在用户实体手机执行验证。

测试使用正式游戏的临时副本 slot6；测试后删除该副本。所有原有玩家数据文件字节未变，仅 Android 自动维护的 profileInstalled 安装元数据变化。备份及截图在工作区 `.research/shattered-runtime/ui182-*`。此次不调整战斗与回收数值；未推送 Git。

APK：`build/artifacts/Shattered-MMO-1.8.2-debug.apk`，版本代码 930。
