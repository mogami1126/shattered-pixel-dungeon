# MMO 1.8.3：种子与符石的回收贡献

按最新规则，种子与符石每件固定贡献 1/3 级，不再作为 0.81 的普通跨类别材料。药水与卷轴每件固定贡献 1 级。装备同类 0.9、异类 0.81 和投掷物排除规则保持不变。

回收单位改为每级 300 单位，以同时精确表达百分之一和三分之一。种子与符石每件 100 单位，药水与卷轴每件 300 单位，装备的原贡献按同比例转换。整批加总后四舍五入一次，不保留余量。因此单件种子/符石最终 0 级，两件最终 1 级，三件精确 1 级；混合两种材料同样累计。

确认说明同时更新中文与英文。新增检查覆盖三件精确等于一级、单件/两件取整、种子符石混合、与药水或装备贡献混合。215 项 MMO 回归检查通过，Android debug 构建通过；未改玩家存档，未推送 Git。

版本：4.0.2-MMO.1.8.3-INDEV，版本码 932。
