# MMO 1.3：实际等级合并、装备分类袋与英烈怪物规则

## 改动

- 同名普通近战武器、防具、戒指、法杖自动合并。显示强化等级 A+B+1：白板实际是 1 级，0+0→1，1+1→3，1+18→20。取消原先 +0～+3、未诅咒、无附魔等门槛。
- 合并前高等级物品的附魔/刻印、诅咒及已去除状态优先，同级保留目标。直接设置完整等级，不循环调用 upgrade。独特装备、投掷武器不自动合并；普通近战武器不再喂给法师魔杖，避免不相关武器不断提高内置法杖等级。
- 加入武器袋、戒指袋，大背包模式新旧存档自动配齐，包含主背包共七标签。旧存档加载时整理已有同名装备，按实际等级求和，不丢弃高级物品的数值贡献。
- 大量掉落使用本地英烈 Mob.rollToDropLoot 与 Challenges.extraLoot 的次数及分支：基础 1～3 抽，MMO 加 round(max(sqrt(1.5^(d−1)),d))。按楼层抽普通物品、财富戒指不同档次消耗品或空结果；取消经验过滤与固定 Boss 30 件奖励。具体物品由当前破碎生成器提供，没有移植英烈对全局道具牌堆的重写。
- 怪物生命、伤害、经验按英烈 MMO.java 乘 1.5^(d−1)，命中/闪避乘楼层 d，基础减伤不额外放大。取消所有玩家实力快照和防具补偿；旧存档怪物在取数时也重新使用固定倍率。此版不调成长平衡。
- 中文、英文挑战说明同步实际规则。
