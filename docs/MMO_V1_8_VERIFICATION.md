# MMO.1.8：英烈敌人成长，不带防秒杀

2026-10-13。依据英烈原始 Git 标签 v1.0.2（d3f7188），不是工作区中修复后的英烈源码。

## 成长公式

原版 actors/buffs/MMO.java 的 SCALING_FACTOR=1.5。第 d 层的成长倍率 G=1.5^(d−1)：敌人生命、伤害及击杀经验乘 G；命中、闪避技能乘 d。MMO 不额外提高防御、移动速度或攻击频率。依赖 MMO 修改器，与无处不在和玩家装备属性无关。

这组公式在 MMO.1.7 已经接入。本版集中命中／闪避与经验倍率入口，补全中文、英文挑战描述，并对1、5、10、15、20、25层进行回归校验。保留现有大数与基础生命坐标实现，不重新引入英烈的 int/float 血量溢出。

## 不移植的防秒杀分支

英烈 Mob.damage 中存在下面的分支，当前破碎没有移植它：

```java
if (mmo != null) {
    if (dmg >= HP && dmg < HP * 2 && HP > HT / 2) {
        dmg /= (Dungeon.depth + 1) * Math.log(Dungeon.depth + 1);
    }
}
```

该分支会把本应致死、但不足当前生命两倍的攻击大幅削弱，不能只根据 MMO Buff 类判断是否带有防秒杀。当前 Mob.damageBase 直接进入普通伤害与死亡处理，不增加该分支，也不增加保留1HP规则。

原版 Boss 的阶段切换、无敌阶段、护盾，以及特定怪物原生的狂暴／复活机制仍按原版运行；本次排除的是 MMO 额外防秒杀。

## 实际发现与修复

新增致死检查在第5层发现：数值倍率乘除后，恰好8点基础血量的致死伤害会得到7.999999999999999，再向下取整成7，造成残留1HP。这与英烈上述分支无关，但会呈现类似不能秒杀的症状。

MmoRules.normalized 仅在数值距离正整数不超过8个浮点ULP时，校正到该整数。正常小数伤害继续累积：例如1−10^−8仍不会被当作1，随后补入10^−8才产生1点伤害。不引入最低伤害、必杀比例、等级门槛或成长平衡。
